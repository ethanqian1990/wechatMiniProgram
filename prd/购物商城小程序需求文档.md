## 1. 项目概述

### 1.1 项目背景
- 微信小程序购物商城，为微信生态内的商家和消费者提供便捷的移动端购物体验
- 依托微信小程序生态，触达海量微信用户，支持微信支付闭环交易

### 1.2 产品定位
- 面向微信用户的B2C购物商城小程序
- 提供完整的商品浏览、购买、支付、售后一体化购物体验

### 1.3 目标用户
- 微信用户（C端消费者）
- 有明确购物需求或冲动消费场景

### 1.4 核心功能（MVP）
| 模块 | 功能 |
|------|------|
| **区域** | 区域选择、区域化商品展示、区域切换 |
| 首页 | Banner轮播、商品推荐 |
| 分类页 | 商品分类、分类展示 |
| 搜索 | 关键词搜索、商品筛选 |
| 购物车 | 加入购物车、数量编辑、删除 |
| 我的 | 订单管理、地址管理、微信支付 |

## 2. 功能需求

### 2.0 区域模块（P0 - 新增）

#### 2.0.1 区域选择
- **位置：** 首页顶部或用户首次进入时弹窗选择
- **区域列表：** 东北、华北、华东、华中、华南、西南、西北等
- **记住选择：** 本地缓存用户选择的区域，切换后实时生效
- **切换入口：** 首页顶部区域名称入口，支持快速切换

#### 2.0.2 区域化商品展示
- **首页推荐：** 根据用户所在区域展示不同的推荐商品
- **分类页：** 各区域分类商品可能不同
- **搜索结果：** 优先展示当前区域商品（可选）

#### 2.0.3 区域配置（后台）
- 区域与商品的关联关系
- 区域默认商品/爆品配置
- 区域 Banner 差异化（可选）

#### 2.0.4 区域数据结构
```
区域表：
- region_id: 区域ID
- region_name: 区域名称（如"华东"、"东北"）
- region_code: 区域编码（如"EC"、"NE"）

商品表（扩展）：
- available_regions: 适用区域列表
- region_priority: 区域展示优先级
```

### 2.5 "我的"模块

#### 2.5.1 用户信息
- 微信头像、昵称
- 登录/注册状态

#### 2.5.2 订单管理
- **订单列表：** 待付款、待发货、待收货、已完成/已取消
- **订单详情：** 商品列表、物流信息、订单金额
- **订单操作：** 付款、取消、确认收货、查看物流

#### 2.5.3 地址管理
- 地址列表（默认地址标识）
- 新增地址（收货人、手机号、省市区、详细地址）
- 编辑/删除地址
- 选择地址（下单时）

#### 2.5.4 微信支付
- 统一下单接口调用（预留商户号配置）
- 支付结果回调
- 支付状态查询
- **注意：** 商户号申请中，后端需预留配置项

### 2.5.6 微信登录
- 使用 wx.login 获取 code
- 换取 openid 作为用户唯一标识
- 使用 getUserProfile 获取昵称头像（如用户授权）
-Session 维护登录态

#### 2.5.5 其他功能（扩展）
- 客服中心
- 设置（通知、清除缓存）
- 关于我们

## 3. 业务流程

### 3.1 购物流程图
```
浏览商品 → 加入购物车 / 直接购买 → 结算 → 提交订单 → 微信支付 → 支付成功 → 订单发货 → 确认收货 → 完成
```

### 3.2 关键页面跳转
```
首页 ─┬─→ 分类页（底部Tab）
     ├─→ 搜索页（点击搜索框）
     ├─→ 商品详情（点击商品卡片）
     ├─→ 购物车（底部Tab）
     └─→ 我的（底部Tab）

我的 ─┬─→ 订单列表 → 订单详情
     └─→ 地址管理 → 新增/编辑地址
```

## 4. 非功能需求

### 4.1 性能
- 页面首屏加载 ≤ 2s
- 接口响应 ≤ 500ms（正常网络）

### 4.2 兼容性
- 微信版本 ≥ 7.0.12
- iOS/Android 微信内均可使用

### 4.3 安全
- HTTPS加密传输
- 用户隐私保护（手机号脱敏）

### 4.4 适配
- 适配不同屏幕尺寸（rpx响应式）
- 暗黑模式（可选）

## 7. 管理后台需求

### 7.1 模块结构

| 模块 | 核心功能 |
|------|----------|
| **商品管理** | 商品列表、商品上下架、商品编辑、SKU管理、库存管理 |
| **分类管理** | 分类树维护、分类关联商品 |
| **订单管理** | 订单列表、订单详情、订单状态修改、发货/取消、售后处理 |
| **用户管理** | 用户列表、用户详情、会员等级 |
| **区域管理** | 区域配置、区域商品关联、区域定价（可选） |
| **库存管理** | 库存监控、补货提醒、出库记录 |
| **数据统计** | 销售额、订单量、热门商品、用户画像 |
| **系统设置** | 管理员账号、角色权限、支付配置 |

### 7.2 商品管理详情

#### 7.2.1 商品列表
- 表格/卡片列表展示
- 筛选：分类、状态（上架/下架）、关键词
- 批量上下架、批量删除
- 查看销量、库存

#### 7.2.2 商品编辑
- 基本信息：名称、描述、图片、详情
- 价格：售价、原价、会员价
- 库存：SKU管理、库存数量、低库存预警
- 关联：分类、区域、标签
- 状态：上架/下架

#### 7.2.3 SKU 管理
- 规格管理（颜色、尺码等）
- SKU 列表：规格组合、价格、库存
- SKU 图片

### 7.3 订单管理详情

#### 7.3.1 订单列表
- 筛选：状态、时间、关键词、区域
- 列表字段：订单号、商品、金额、买家、状态、时间
- 批量操作：发货、备注

#### 7.3.2 订单详情
- 买家信息：收货地址、联系方式
- 商品信息：商品列表、数量、金额
- 物流信息：快递公司、快递单号
- 订单操作：发货、修改价格、取消、备注

#### 7.3.3 订单状态
| 状态 | 说明 |
|------|------|
| 待付款 | 等待用户支付 |
| 待发货 | 已支付，待商家发货 |
| 待收货 | 已发货，运输中 |
| 已完成 | 已确认收货 |
| 已取消 | 已取消/退款 |
