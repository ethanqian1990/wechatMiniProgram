## 1. 技术架构概述

### 1.1 技术栈选型

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| **框架** | UniApp Vue3 | 跨平台小程序（微信/支付宝等），Vue3 组合式 API |
| **状态管理** | Pinia | 轻量级状态管理，支持持久化 |
| **HTTP** | uRequest (拦截器封装) | 统一请求封装、token 管理、错误处理 |

| **路由** | UniApp Router |pages.json 配置式路由 |
| **构建** | Vite + HBuilderX | 开发热更新，生产打包 |

#### 2.0.1 区域选择器组件

```
组件: RegionPicker
位置: 首页顶部 Bar
触发: 点击区域名称展开
动画: 上滑淡入 (200ms ease-out)
```

**UI 规格：**
- 弹窗背景：`rgba(0,0,0,0.45)`
- 选项卡片：圆角 12px，白色背景
- 选中态：活力红边框 + 浅红背景 (`#FFECEB`)
- 区域选项布局：2 列宫格

**数据结构：**
```javascript
interface Region {
  id: string;        // 'EC', 'NC', 'SC', 'NE'
  name: string;      // '华东', '华北', '华南', '东北'
  enabled: boolean;  // 是否启用
}
```

**持久化：**
- 缓存 key: `demo_region`
- 首次进入：弹窗选择（无缓存时）
- 切换：实时更新并刷新首页

#### 2.0.2 区域状态管理 (Pinia)

```javascript
// store/region.js
export const useRegionStore = defineStore('region', {
  state: () => ({
    currentRegion: storage.get('demo_region') || 'EC',
    regionList: []
  }),
  getters: {
    regionName: (state) => {
      const r = state.regionList.find(i => i.id === state.currentRegion);
      return r?.name || '华东';
    }
  },
  actions: {
    setRegion(id) {
      this.currentRegion = id;
      storage.set('demo_region', id);
    }
  }
});
```

- **支付成功但页面未刷新：** 以订单状态查询接口为准

### 4.3 请求封装

```javascript
// utils/request.js
const request = (options) => {
  return new Promise((resolve, reject) => {
    const token = storage.get('token');
    uni.request({
      url: API_BASE + options.url,
      method: options.method || 'GET',
      header: {
        'Authorization': token ? `Bearer ${token}` : '',
        'Content-Type': 'application/json'
      },
      data: options.data,
      success: (res) => {
        if (res.statusCode === 200) {
          resolve(res.data);
        } else if (res.statusCode === 401) {
          // token 过期，重新登录
          reject('UNAUTHORIZED');
        } else {
          reject(res.data);
        }
      },
      fail: reject
    });
  });
};
```
