## 1. 项目概述

### 1.1 项目背景
微信购物商城小程序后端服务，为微信小程序提供完整的商品浏览、购买、支付、售后一体化购物体验的后端支撑。

### 1.2 技术栈选型

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 语言 | Go 1.21+ | 高性能、高并发 |
| Web框架 | Gin | 轻量级、高性能 |
| ORM | GORM | Go语言ORM |
| 数据库 | MySQL 8.0 | 主数据库 |
| 缓存 | Redis 7.x | 会话、热点数据缓存 |
| 配置文件 | Viper | YAML配置管理 |
| API文档 | Swagger/OpenAPI | 自动生成API文档 |
| 定时任务 | Cron | 订单超时取消等 |
| 微信SDK | wechatpay-go | 微信支付 |

## 3. 数据库设计

### 3.1 核心表结构

#### 3.1.1 用户表 (users)

```sql
CREATE TABLE users (
    id              VARCHAR(36) PRIMARY KEY COMMENT '用户ID',
    openid          VARCHAR(128) UNIQUE COMMENT '微信openid',
    nickname        VARCHAR(100) COMMENT '用户昵称',
    avatar          VARCHAR(500) COMMENT '头像URL',
    phone           VARCHAR(20) COMMENT '手机号',
    status          TINYINT DEFAULT 1 COMMENT '状态: 1正常 0禁用',
    last_login_at   DATETIME COMMENT '最后登录时间',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at      DATETIME DEFAULT NULL,
    INDEX idx_openid (openid),
    INDEX idx_phone (phone)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

#### 3.1.2 区域表 (regions)

```sql
CREATE TABLE regions (
    id              VARCHAR(36) PRIMARY KEY,
    region_name     VARCHAR(50) NOT NULL COMMENT '区域名称如华东、东北',
    region_code     VARCHAR(20) UNIQUE COMMENT '区域编码如EC、NE',
    is_enabled      TINYINT DEFAULT 1 COMMENT '是否启用',
    sort_order      INT DEFAULT 0 COMMENT '排序',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_enabled (is_enabled),
    INDEX idx_sort (sort_order)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='区域表';
```

#### 3.1.3 商品分类表 (categories)

```sql
CREATE TABLE categories (
    id              VARCHAR(36) PRIMARY KEY,
    name            VARCHAR(50) NOT NULL COMMENT '分类名称',
    parent_id       VARCHAR(36) DEFAULT NULL COMMENT '父分类ID',
    level           TINYINT DEFAULT 1 COMMENT '层级:1一级 2二级',
    icon            VARCHAR(500) COMMENT '图标',
    sort_order      INT DEFAULT 0,
    is_enabled      TINYINT DEFAULT 1,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_parent (parent_id),
    INDEX idx_level (level),
    INDEX idx_enabled (is_enabled)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='商品分类表';
```

#### 3.1.4 商品表 (products)

```sql
CREATE TABLE products (
    id              VARCHAR(36) PRIMARY KEY,
    name            VARCHAR(200) NOT NULL COMMENT '商品名称',
    description     TEXT COMMENT '商品描述',
    main_image      VARCHAR(500) COMMENT '主图URL',
    images          JSON COMMENT '图片列表',
    category_id     VARCHAR(36) COMMENT '分类ID',
    price           DECIMAL(10,2) NOT NULL DEFAULT 0 COMMENT '售价',
    original_price  DECIMAL(10,2) DEFAULT NULL COMMENT '划线价/原价',
    stock           INT DEFAULT 0 COMMENT '总库存',
    sales_count     INT DEFAULT 0 COMMENT '销量',
    is_on_shelf     TINYINT DEFAULT 1 COMMENT '是否上架:1上架 0下架',
    show_on_home    TINYINT DEFAULT 0 COMMENT '是否在首页展示',
    available_regions JSON COMMENT '可售区域ID列表',
    tags            JSON COMMENT '标签如营销标签',
    promo_text      VARCHAR(200) COMMENT '促销文案',
    low_stock_threshold INT DEFAULT 10 COMMENT '低库存预警阈值',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at      DATETIME DEFAULT NULL,
    INDEX idx_category (category_id),
    INDEX idx_on_shelf (is_on_shelf),
    INDEX idx_show_home (show_on_home),
    INDEX idx_sales (sales_count DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='商品表';
```

#### 3.1.5 商品SKU表 (product_skus)

```sql
CREATE TABLE product_skus (
    id              VARCHAR(36) PRIMARY KEY,
    product_id      VARCHAR(36) NOT NULL,
    sku_name        VARCHAR(200) NOT NULL COMMENT 'SKU名称如颜色+尺码',
    specs           JSON NOT NULL COMMENT '规格详情{"color":"红色","size":"XL"}',
    price           DECIMAL(10,2) NOT NULL COMMENT '售价',
    original_price  DECIMAL(10,2) DEFAULT NULL COMMENT '划线价',
    stock           INT DEFAULT 0 COMMENT '库存',
    image           VARCHAR(500) COMMENT 'SKU图片',
    is_enabled      TINYINT DEFAULT 1,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_product (product_id),
    INDEX idx_enabled (is_enabled),
    FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='商品SKU表';
```

#### 3.1.6 购物车表 (carts)

```sql
CREATE TABLE carts (
    id              VARCHAR(36) PRIMARY KEY,
    user_id         VARCHAR(36) NOT NULL,
    product_id      VARCHAR(36) NOT NULL,
    sku_id          VARCHAR(36) DEFAULT NULL,
    quantity        INT NOT NULL DEFAULT 1,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_user (user_id),
    INDEX idx_user_product (user_id, product_id, sku_id),
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE,
    FOREIGN KEY (sku_id) REFERENCES product_skus(id) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='购物车表';
```

#### 3.1.7 收货地址表 (addresses)

**订单状态流转:**
```
PENDING_PAY (待付款) ──支付成功──> PENDING_SHIP (待发货)
PENDING_SHIP ──商家发货──> SHIPPED (待收货)
SHIPPED ──确认/自动收货──> FINISHED (已完成)
PENDING_PAY ──用户取消/超时──> CANCELED (已取消)
```

## 5. 核心业务逻辑

### 5.1 微信登录流程

```
1. 小程序调用 wx.login() 获取 code
2. 小程序将 code 发送到后端 /user/wx_login
3. 后端用 code 换取 openid (通过微信 API)
4. 后端查询/创建用户记录
5. 后端生成 JWT Token 返回
6. 小程序后续请求带上 Token
```

### 5.2 创建订单流程

```
1. 校验购物车商品(库存、商品状态、区域可售)
2. 校验收货地址
3. 计算订单金额
4. 幂等校验(client_order_token)
5. 冻结库存(创建预占库存记录)
6. 创建订单记录(status=PENDING_PAY)
7. 返回订单信息
8. 15分钟超时未支付自动取消(定时任务)
```

### 5.3 支付流程

```
1. 用户确认支付
2. 调用 /pay/create 创建预支付单
3. 调用微信统一下单接口
4. 返回支付参数给小程序
5. 小程序调起微信支付
6. 支付成功后微信回调 /pay/callback
7. 后端验签、更新订单状态、释放冻结库存
8. 前端轮询订单状态或被动接收状态更新
```

### 5.4 库存扣减规则

| 阶段 | 库存操作 |
|------|----------|
| 创建订单(PENDING_PAY) | 冻结库存 |
| 支付成功 | 冻结→已扣减 |
| 取消/超时 | 释放冻结 |

### 5.5 首页数据获取

```
1. 获取当前区域ID(从用户缓存/参数)
2. 获取区域配置的Banner列表
3. 获取主推商品:
   - 规则=自动: 取销量第1的商品
   - 规则=指定: 取指定的商品(需校验可售)
4. 获取商品列表:
   - 筛选: 上架+首页展示+当前区域可售
   - 排序: 销量降序
   - 截取: 取前N条(区域配置)
5. 分类筛选(可选): 按首页内分类筛选
```

### 6.1 认证授权

| 需求 | 实现方式 |

- 请求限流 (每IP 100次/分钟)
- 参数校验
- SQL注入防护
- XSS防护

### 6.3 敏感信息

- 手机号脱敏显示
- 微信openid不直接暴露
- 日志脱敏处理
